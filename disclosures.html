Gummicube (Airship)

Airship VDP · direct Web Application Security · XSS 1 finding May 2026 · Remote
★ HALL OF FAME
Reflected XSS in blog search — four reflection contexts HIGH

The blog search on www.gummicube.com/blog/search/<term>/ reflected user input without output encoding in four distinct contexts: the page <title>, Open Graph & Twitter Card meta descriptions, JSON-LD structured data (injected via dangerouslySetInnerHTML) and visible page content. A crafted URL carrying test"><script>alert(document.domain)</script> broke out of the existing HTML context and executed arbitrary JavaScript in the victim's browser — demonstrated with curl evidence showing the raw injected script tag in the HTTP response.

Impact: session cookie/token theft enabling account takeover, attacker-driven actions as the victim, phishing redirects and page defacement — particularly serious because Gummicube's contact forms collect personal data (name, email, company, app details) that a crafted link could capture from employees and customers.

confirmed & addressed by the Airship Security Team curl PoC — raw script injection in the HTTP response fix: context-aware output encoding + safe JSON-LD serialization
